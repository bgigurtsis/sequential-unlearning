# Gao et al. — On Large Language Model Continual Unlearning (O3)

arXiv:2407.10223 — ICLR 2025 (openreview id Essg9kb4yx). Verified: y.

## Setup
- Base: LLaMA-2-7B; OOD detector on RoBERTa-large. O3 trains only ~20M params (orthogonal LoRA per request) vs 6,758M for full-model baselines.
- Continual requests: ScienceQA 4 domains (bio→phys→chem→econ); TOFU 3 forget sets (forget01/05/10); CLINC150 3 domains. No retain data used.

## Reported numbers (after request 3)
- ScienceQA: O3 keeps CommonsenseQA 78.5 / OpenbookQA 80.9 (base 88.0 / 88.7); retained-distribution 91.2 vs base 99.8.
- TOFU: O3 Real Authors 88.8 / World Facts 86.1 vs base 89.0 / 86.3 (essentially no loss); retained-distribution 84.9 vs 85.8.
- CLINC150: MRPC 86.6 / RTE 89.0 vs base 88.0 / 88.7.
- Baseline collapse: GradDif and SOGD produce empty or repeated-token nonsense by request 2–3 (all tasks). EUL by request 3: MRPC 81.3, RTE 76.3. PO/SOPO inconsistent; NPO degrades progressively on QA tasks.

## Relevance to H4
- Structural isolation (one orthogonal LoRA per request, gated at inference) makes per-request interference ~zero by construction — accumulated leakage across requests approximately additive-in-nothing.
- Caveat for us: the base weights are untouched, so this is closer to CURaTE-style gating than true erasure; removing the adapters restores knowledge. If our protocol demands weight-level erasure, O3 numbers are an optimistic bound, not a direct estimate.
- The 4–9 point drop on general QA after only 3 requests (ScienceQA setting) even for the best method shows entangled-domain unlearning costs real utility.

## Addendum (T2 perspective)


Chongyang Gao, Lixu Wang, Kaize Ding, Chenkai Weng, Xiao Wang, Qi Zhu. arXiv 2407.10223. **ICLR 2025.** Verified: y.

Method: **O3** = Orthogonal low-rank adapters + an Out-Of-Distribution detector that gates which adapter is applied. Requires no retained data.

Base model: LLaMA2-7B.

## Sequential protocol
3 requests per task, across three tasks:
- QA (ScienceQA): biology → physics → chemistry → economics
- Fictitious knowledge (TOFU): forget01 → forget05 → forget10
- Intent classification (CLINC150): work → travel → home

## Numbers copied out
**ScienceQA (Table 3):** GradAsc fails entirely after request 2 (utility → 0% on World Facts). NPO retains ~87% utility across requests. O3 holds ~88-89% consistently.

**TOFU (Table 2):** GradAsc catastrophic collapse after request 2 (0% on Real Authors). SOPO 85.3% → 86.7% across requests. O3 preserves 88.8-89%.

**CLINC150 (Table 4):** EUL drops 88.1% → 76.3% on RTE by request 3. SOGD crashes to ~2-4% on MRPC/RTE. O3 maintains 87-89% across all requests.

## Relevance to T1 / H1
The single most on-point paper for the forgetting arm's *structure*: it shows that cumulative collateral over sequential requests is not inevitable, and that the fix is architectural — keep each request's update in an orthogonal low-rank subspace instead of letting them pile into the same weights.

Two hard limits on how far this supports H1:
1. **3-4 requests, not 30.** The utility curves are flat over the tested range, but nothing here establishes flatness at n=30.
2. O3's gating is OOD-detector-driven at inference. For our purposes the transferable part is the orthogonal-LoRA-per-day construction, not the router.

Also note the baseline behaviour, which is our real warning: gradient-ascent-family methods are already dead by request 2.
